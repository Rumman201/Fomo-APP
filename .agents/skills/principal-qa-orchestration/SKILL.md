# Principal QA Orchestration Skill

## Purpose
Establishes the enterprise quality architecture, coverage matrices, defect severity classifications, and release candidate qualification criteria across all subsystems.

## Core Directives
1. Define objective, evidence-based quality gates.
2. Enforce risk-based test prioritization (P0 Blocker, P1 Critical, P2 High, P3 Normal).
3. Ensure 100% requirement traceability from specification to automated test execution.
