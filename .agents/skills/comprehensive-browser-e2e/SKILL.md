# Comprehensive E2E Journey Verification Skill

## Purpose
Governs end-to-end verification of user journeys, view transitions, navigation state preservation, and viewholder binding across mobile UI screens.

## Core Directives
1. Validate primary user workflows (app launch, search, city selection, hourly weather inspection).
2. Verify ViewModel state flow (Loading, Success, Error, Offline).
3. Test edge-case UI inputs (empty search, long city names, rapid interaction debouncing).
