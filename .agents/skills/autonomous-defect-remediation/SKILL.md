# Autonomous Defect Remediation Skill

## Purpose
Governs the disciplined reproduction, root-cause diagnosis, safe code modification, and regression testing for all confirmed defects.

## Core Directives
1. Never speculate: write a reproducing failing test before modifying implementation code.
2. Maintain architectural boundaries and backwards compatibility (`minSdk 24`).
3. Preserve all Phase 6 security controls, Phase 7 performance optimizations, and Phase 8 CI/CD pipelines.
