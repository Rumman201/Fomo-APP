# AI/MLOps Lifecycle Operations Skill

## Purpose
Governs the operational verification, regression protection, and update lifecycle for on-device meteorological intelligence algorithms.

## Core Directives
1. Validate Steadman polynomial equations and AI advisories against empirical WMO standards in CI.
2. Maintain zero cloud LLM dependencies to eliminate token costs and network latency.
3. Test edge conditions (e.g. extreme temperatures, zero humidity) on every build.
