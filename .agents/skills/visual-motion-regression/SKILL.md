# Visual & Motion Regression Verification Skill

## Purpose
Guarantees visual rendering stability, design system consistency, multi-density layout integrity, and animation smoothness without jank.

## Core Directives
1. Verify layout responsiveness across small phone (320dp), standard phone (360-411dp), and tablet (600dp+) densities.
2. Ensure animations respect Android system `animator_duration_scale` and reduced-motion settings.
3. Validate typography token rendering and eliminate layout shifts/overdraw.
