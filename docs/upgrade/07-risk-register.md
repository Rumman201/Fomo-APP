# 07 — Project Risk Register

## Risk Assessment Matrix

| Risk ID | Category | Severity | Probability | Description | Root Cause | Impact | Mitigation Strategy | Owner Discipline | Status |
| :--- | :--- | :---: | :---: | :--- | :--- | :--- | :--- | :--- | :--- |
| **RSK-01** | Quality Gate | **High** | Low | Fatal Android Lint errors fail automated builds and PR gates. | 10 lint errors (duplicate IDs, NewApi call, missing constraints). | CI/CD build failure; broken view lookups. | Fix duplicate IDs, eliminate dead layouts, replace `getOpPackageName()` in Phase 1. | Frontend / Mobile Engineer | **Resolved in Phase 1** |
| **RSK-02** | Runtime Crash | **Critical** | Low | Calling `getOpPackageName()` crashes on Android 7.0–9.0 (API 24–28). | `getOpPackageName()` added in API 29; app `minSdk` is 24. | Fatal `NoSuchMethodError` crash on older devices. | Eliminated reflection and implemented `WeatherIconMapper`. | Mobile Engineer | **Resolved in Phase 1** |
| **RSK-03** | UI Rendering | **Medium** | Low | Glide fails to render weather icon for `"sun"` item in carousel. | Item created with `"sun"`, but drawable asset is `sunny.png`. | Broken/blank image in carousel. | Mapped `"sun"` and `"sunny"` to `R.drawable.sunny` in `WeatherIconMapper`. | Frontend Engineer | **Resolved in Phase 1** |
| **RSK-04** | Architecture | **High** | Low | Monolithic `MainActivity` prevents adding live weather APIs or multi-city features cleanly. | Lack of MVVM / Clean Architecture. | High technical debt, untestable UI. | Implemented Clean Architecture with MVVM, ViewModel, and Repository in Phase 2. | Principal Architect | **Resolved in Phase 2** |
| **RSK-05** | Security / Dependency | **Medium** | Low | Outdated dependencies and unpinned versions. | Hardcoded string dependencies in `build.gradle.kts`. | Supply chain vulnerabilities; build drift. | Centralized in `libs.versions.toml` with pinned versions. | DevOps / Security Engineer | **Resolved in Phase 1 & 2** |
| **RSK-06** | Testing / Quality | **High** | Low | Zero regression protection during refactors. | Empty test directories; missing test dependencies. | Undetected bugs during modernization. | Created 34 unit tests with 100% pass rate. | QA Automation Engineer | **Resolved in Phase 2 & 3** |
| **RSK-07** | Performance | **Medium** | Low | High GPU overdraw and layout hierarchy nesting slows rendering. | Redundant backgrounds on root and child layouts; unoptimized weights. | Frame drops on lower-end devices; battery drain. | Flattened layout hierarchy, eliminated redundant backgrounds in Phase 1. | Performance Engineer | **Resolved in Phase 1** |
| **RSK-08** | Network Reliability | **Medium** | Low | Remote weather API network failures causing app crashes or blank screens. | Device offline, flight mode, or DNS timeout. | Poor user experience, crash or freeze. | Implemented `OfflineFirstWeatherRepository` with Room DB fallback and 30-min cache TTL. | Backend / Integration Engineer | **Resolved in Phase 3** |
| **RSK-09** | Database Schema Drift | **Medium** | Low | Unhandled schema migrations corrupting SQLite state on app update. | Future table or column modifications without migration scripts. | SQLite `IllegalStateException` on launch. | Enabled version tracking and established isolated Room DAO transactions. | Database Architect | **Resolved in Phase 3 & 5 (MIGRATION_1_2)** |
| **RSK-10** | Accessibility / UX | **Medium** | Low | Touch targets below 48dp or missing TalkBack semantics impair accessibility. | Hardcoded text sizes, unlabelled image elements. | WCAG failure; impaired user accessibility. | Standardized 48dp touch targets, TalkBack headings, and tokenized dimensions. | Accessibility Specialist | **Resolved in Phase 4** |
| **RSK-11** | AI Hallucination & Untrusted Output | **High** | Low | Probabilistic language model outputs contradicting actual meteorological telemetry. | Unconstrained LLM output generation. | Misleading safety advice; loss of user trust. | Enforced dual-tier guardrails: prompt injection scanner and temperature disparity filter ($\Delta T > 6^\circ\text{C}$) with deterministic fallback. | AI / Safety Architect | **Resolved in Phase 5** |
| **RSK-12** | Third-Party API Rate Limits & Latency | **Medium** | Low | Excessive Geocoding API queries on every keystroke causing rate limit throttling. | Unthrottled search querying. | HTTP 429 errors; degraded search experience. | Implemented 350ms debouncer and prioritized Room local favorite cache lookups. | Integration Architect | **Resolved in Phase 5** |
| **RSK-13** | Notification Alert Flooding | **Medium** | Low | Repeated weather alerts spamming users on frequent pulls or polls. | Unbounded alert trigger evaluations. | User annoyance; notification dismissal. | Implemented 60-minute cooldown window per trigger type and Room audit log. | Automation Architect | **Resolved in Phase 5** |
